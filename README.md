This project is a travel booking website built using the MEAN stack (MongoDB, Express, Angular, Node.js). It has two parts: a customer-facing website where users can view trip packages, and an admin dashboard where trips can be added, edited, or deleted.

The customer side uses Express and Handlebars to show available trips. The admin side is a single-page application built with Angular that lets admins manage trips through a secure login system. Everything connects through a RESTful API and stores data in MongoDB.

I learned a lot building this, especially how the frontend and backend work together, how to protect routes using JWT tokens, and how to structure an Angular project. I also got to practice testing endpoints with tools like Postman and curl.

This was my final project for CS 465 and it's the most complete full stack app I’ve built so far.
